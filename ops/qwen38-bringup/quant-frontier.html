Deploy target

Q2_K_XL · 9.9 GB · instruct

The smallest quant that gives up nothing measurable: code 0.896, hard math 90%, long-context recall 100% — all tied with the 16.7 GB baseline, while freeing ~7 GB of VRAM for a bigger context window. Going one rung further to IQ2_M saves just 0.3 GB but breaks deep long-context recall. Serve it with enable_thinking:false; all quants keep the MTP draft head for speculative decode.

The full ladder

Method & caveats

Subject: Qwen3.8-27B, unsloth dynamic (UD) GGUFs + bartowski imatrix Q4_K_M, llama.cpp fast path, draft-mtp (exact at temp 0), greedy. Code: HumanEval+ 164 via evalplus. Hard math: MATH-500 Level-5, n=50, extracted \boxed{} + sympy equivalence (scorer self-test 10/11). Long-context: single-needle NIAH, chat endpoint, q4_0 KV, no-MTP. Thinking gate on the base quant: code instruct 89.0 vs 86.7 (budget 8192); GSM8K 96.7 vs 95.0; MATH-L5 92.0 vs 80.0 (high). Noise: code ±~4.8pp at n=164, math ±~9pp at n=50 — the flat spreads sit within it. Long-context cells are one sample each; IQ2_M’s elevated miss-rate vs the base’s clean 100% is the signal.

Bottom line. A 27B coder compresses from 16.7 GB to 9.9 GB with no measurable quality loss on code or competition math, and full long-context recall. Push to ~2.4-bit (IQ2_M, 9.6 GB) and the only thing that breaks is sporadic deep-context needle recall. Thinking is a null-to-negative lever throughout.  ·  Local model lifecycle lab — measured on one headless RTX 3090.
