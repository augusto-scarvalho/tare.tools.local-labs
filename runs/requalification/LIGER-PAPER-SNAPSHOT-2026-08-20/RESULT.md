# LIGER-PAPER-SNAPSHOT-2026-08-20 — result

**Decision:** BLOCKED at cached recurrence. The historical paper snapshot passes
exact state transfer and finite BF16 forward/backward, but its incremental path
is structurally and numerically inconsistent with its full causal path. No
checkpoint was downloaded and no fine-tuning was started.

## Gate results

| Gate | Result | Evidence |
|---|---|---|
| provenance | PASS | all three worktrees clean at exact historical SHAs |
| environment | PASS | original Transformers 4.47.1 stack imports; lock frozen |
| state transfer | PASS | 361,088 parameters each; strict load; zero differences |
| construction | PASS | logits `[1,8,256]`; finite logits/loss/gradients |
| repeatability | PASS | two valid fresh processes reproduce all scalars exactly |
| recurrence | **FAIL** | wrong cache length and large full-vs-incremental error |

The two valid trials both measured:

- loss: `5.574553966522217`;
- cache lengths after tokens 1..8: `[4,8,12,16,20,24,28,32]` rather than
  `[1,2,3,4,5,6,7,8]`;
- full-vs-incremental `max_abs=0.935546875` (threshold `0.05`);
- `max_rel=39322.6015625` (threshold `0.05`).

The large relative error is amplified by near-zero logits, but the absolute
error alone exceeds tolerance by 18.7x.

## Root-cause attribution

The cache-length pattern exactly matches the four query heads in the reduced
config. The upstream attention stores `offset=q.shape[1]` while `q` has layout
`[batch, heads, sequence, dimension]`; it therefore advances by head count, not
token count. This is a direct source/data match, not a timing inference.

The numerical divergence has a second declared mechanism: the output is a 50/50
blend of recurrent GLA and 64-token local FlashAttention, but only the recurrent
state is persisted in `FlaCache`; local-attention K/V updates are commented out.
Tokenwise decoding therefore cannot reproduce the full local-attention branch.
Fixing the offset alone is not sufficient for recurrence parity.

## Receipt handling

The first valid trial wrote Python bytecode into the source tree because upstream
does not ignore all `__pycache__` paths. The immediate `TRIAL2.json` correctly
failed the provenance gate and is retained. Generated bytecode directories were
moved, not deleted, to a recovery area outside the clone; the clean repeat used
`PYTHONDONTWRITEBYTECODE=1` and is `TRIAL2B_REPEAT.json`.

## Research consequence

The paper snapshot supports training/full-sequence mechanism experiments but is
not a qualified cached-inference substrate. Using its released checkpoint for
latency, constant-memory decoding, or local serving before a separately qualified
cache patch would confound architecture quality with an invalid execution path.

A follow-up fork should test two changes independently: sequence-length offset,
then a declared local-K/V cache (or a GLA-only ablation). That work is a patched
replication and must not be reported as untouched upstream behavior.
