## 8. Mechanism + state-isolation proof (§16) — the headline
- Mechanism active: **24 LiZAttention modules** replaced all `self_attn`; shared `LCache`; delta-rule
  runs; training loss falls (init≈broken at mag 0.5 → 3.23). UPSTREAM_MECHANISM = REPRODUCED.
- **State-isolation FAILED:** sample B's logits shift by **max |Δ| = 21.35** depending on whether
  sample A ran first → `isolated=false`. The shared LCache persists delta-rule state across independent
  forward calls; the default `get_tptt_model` integration never resets between sequences → cross-sample
  (and cross-batch) contamination. **Per §16 this INVALIDATES the TPTT quality numbers; per §20 it is a
  stop condition.**
- **Confirmed fixable:** `lcache.reset()` before each sequence restores **BIT_EXACT isolation (0.0)**
  (`runs/rnn/RNN-08-tptt/state_isolation_confirm.json`). LCache API: `{inputs_states, reset, update}`.

## 9. Failures / negative evidence (honesty)
